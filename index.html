What I built

A prototype for an AI dispute-analysis workflow that separates invalid reasoning from valid disagreement before making a recommendation.

How AI is used

The intended model call uses a strict rubric and JSON schema to return validity checks, harmful-pattern flags, psychology-informed analysis, and unresolved assumptions.

What I learned

AI is more useful in sensitive disagreement when it is constrained by transparent rules, privacy defaults, and clear separation between argument patterns and personal character.
