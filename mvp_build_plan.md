# MVP Build Plan

## Showcase Version

Goal: build a working prototype that demonstrates the serious Fair Argument
Analysis model clearly, without requiring a user network or crowd-vote database.

1. Static interactive prototype
   - Input form
   - Sample dispute
   - Structured local report
   - Showcase explanation

2. LLM integration
   - Add server-side API route - completed
   - Use a structured output schema - completed
   - Keep user submissions private by default
   - Store no dispute text unless the user opts in

3. Evaluation set
   - Valid disagreement
   - Repairable invalid argument
   - Coercive argument pattern
   - Optional lens selected
   - Missing evidence case

4. Showcase polish
   - Add demo examples
   - Add "what I built, how AI was used, what I learned"
   - Add privacy note
   - Record a short walkthrough

## Future Product Ecosystem

1. Crowd Vote
   - Casual A/B voting
   - Age-group breakdowns
   - Short reasoning
   - Similar-question database
   - Free use tied to participation
   - Paid use without participation

2. Fair Analysis
   - Free serious help
   - Private by default
   - Psychology-informed
   - Optional lenses only when preselected
   - Safety-aware guidance

The crowd product can grow the audience, while the Fair Analysis product stays
separate, private, and useful even before the crowd network exists.
