Short Description

Fair Argument Analysis is a private AI-assisted prototype that helps users review serious disagreements. It evaluates each argument separately, rejects invalid or harmful reasoning patterns, and uses psychology-informed criteria as the default tie-breaker when valid arguments remain.

What I Built

I built a browser-based prototype with an argument intake form, sample dispute, structured analysis report, supporting model specification, and a test-case review panel. The app shows how an AI system can separate popularity, logic, emotional safety, and psychology-informed reasoning.

How I Used AI

AI was used to design the evaluation framework, define safety and validity categories, draft the model prompt, and build the working prototype. The deployed version uses a server-side OpenAI Responses API endpoint with strict JSON output to return validity checks, harmful-pattern flags, psychology-informed analysis, recommendations, confidence, and unresolved assumptions.

What I Learned

I learned that a useful AI dispute tool should not simply choose a winner. It needs a careful decision architecture: safety screen first, validity gate second, psychology-informed comparison third, and optional worldview lenses only when selected before analysis begins.

Future Direction

The serious analysis tool could remain free and private, while a separate casual crowd-vote product could support the ecosystem through lightweight A/B decisions, age-group sentiment, and participation-based access.

Privacy Note

This prototype does not include account creation or a database. Hosted AI analysis is sent to the serverless API only to generate the report. A production version should add clearer retention controls, deletion options, and consent language before accepting sensitive real-world disputes.
